# Bond (mobile app)

Bond is a B2B collaboration-matching phone app for small businesses, built with Expo.

@AGENTS.md

## Project docs — the source of truth

All information about app development and features lives in [`docs/`](docs/).
Read the relevant doc before building or changing a screen, feature or style,
and follow it over assumptions or defaults. If a doc and the code disagree, or a
doc doesn't cover what's needed, ask rather than invent.

- [`docs/bond-app-structure.md`](docs/bond-app-structure.md) — product summary, global layout, screens and navigation
- [`docs/bond-features.md`](docs/bond-features.md) — features, data model and matching logic
- [`docs/bond-brand-kit.md`](docs/bond-brand-kit.md) — brand, voice, design tokens and visual styling
- [`docs/bond-demo-data.md`](docs/bond-demo-data.md) — hardcoded fictional demo seed data and its rules

When a decision changes how the app works, update the matching doc in the same change.
